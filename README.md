Credit Risk Analysis System

Project Overview

A Machine Learning based Credit Risk Analysis System developed using Python.

This project analyzes customer financial data and predicts credit risk using Machine Learning techniques.

Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

Project Files

- Credit_Risk_Analysis_System.ipynb
- best_credit_risk_model.pkl
- final_credit_risk_dataset.csv
- final_credit_risk_recommendations.csv
- credit_risk_dashboard_results.csv

Objective

To analyze credit risk and support better financial decision-making using Machine Learning.
